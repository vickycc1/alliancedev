# PRD: 前后端联调 — API 对接 (T-9.1.1)

## 概述

将前端所有页面的 API 调用与后端实际接口对齐，确保路径、请求体、响应体类型完全匹配后端 Controller 定义。后端接口前缀统一为 `/api`（Vite 代理至 `http://localhost:8080`）。

## 后端 DTO 字段对照

### UserResponse
```
id: Long, username: String, nickname: String, avatar: String,
email: String, phone: String, bio: String, status: Integer,
roles: List<String>, createdAt: LocalDateTime, updatedAt: LocalDateTime,
lastLoginAt: LocalDateTime
```

### PostResponse（列表和详情共用）
```
id: Long, categoryId: Long, categoryName: String, author: UserResponse,
title: String, content: String, summary: String, viewCount: Integer,
likeCount: Integer, commentCount: Integer, favoriteCount: Integer,
shareCount: Integer, isTop: Integer, isEssence: Integer,
aiRequested: Integer, status: Integer, aiResponse: AiResponseDTO,
liked: Boolean, favorited: Boolean, createdAt: LocalDateTime, updatedAt: LocalDateTime
```

### CommentResponse
```
id: Long, postId: Long, parentId: Long, author: UserResponse,
replyToUser: UserResponse, content: String, likeCount: Integer,
status: Integer, liked: Boolean, createdAt: LocalDateTime,
children: List<CommentResponse>
```

### CategoryTreeResponse
```
id: Long, parentId: Long, name: String, icon: String,
description: String, sortOrder: Integer, status: Integer,
postCount: Integer, createdAt: LocalDateTime,
children: List<CategoryTreeResponse>
```

### LoginResponse
```
token: String, refreshToken: String, expiresIn: Long, user: UserResponse
```

## 前端需修复的 API 不匹配项

### 一、路径不匹配（前端调错路径）

| 前端当前路径 | 后端正确路径 | 涉及文件 |
|-------------|-------------|---------|
| GET /categories | GET /categories/tree | Home, Search, CategoryCascader |
| GET /user/profile | GET /auth/me | useAuthStore |
| GET /user/{id} | 无此接口（需用 /posts?authorId= 替代） | Profile |
| PUT /user/profile | 无此接口（需新增或用 /auth/me 替代） | Profile |
| PUT /user/password | 无此接口 | ChangePasswordModal |
| GET /posts/{id}/comments | GET /comments/post/{id} | CommentList |
| POST /posts/{id}/comments | POST /comments (body含postId) | CommentInput, CommentList |
| GET /user/posts | 无此接口（用 /posts?authorId= 替代） | UserContentTabs |
| GET /user/comments | 无此接口 | UserContentTabs |
| GET /user/favorites | 无此接口 | UserContentTabs |

### 二、响应类型不匹配

| 前端期望 | 后端实际 | 涉及文件 |
|---------|---------|---------|
| POST /posts → Result\<PostListItem\> | Result\<Long\> (仅返回postId) | NewPost |
| POST /comments → Result\<CommentWithUser\> | Result\<Long\> (仅返回commentId) | CommentInput |
| GET /posts → PageResult\<PostListItem\> | PageResult\<PostResponse\> (PostResponse含content等完整字段) | Home, Search |
| User.roles: RoleCode[] | UserResponse.roles: List\<String\> | 类型定义 |
