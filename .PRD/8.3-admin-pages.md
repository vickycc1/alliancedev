# PRD: 前端管理后台页面 (T-8.3)

## 概述

基于开发任务分解文档 8.3 节，在 `admin/` 独立项目中实现后台管理页面。项目技术栈为 React 18 + TypeScript + Ant Design 5 + Zustand + Vite，端口 3001，API 代理至后端 8080。

## 已有基础

- AdminLayout（侧边栏+顶栏+Outlet）✅
- Login 页面 ✅
- Dashboard 基础版（静态统计卡片）✅
- 路由守卫（AdminGuard / GuestGuard）✅
- API 封装（axios + token 管理）✅
- Auth Store ✅
- 类型定义（common.ts / user.ts）✅
- 路由占位（users/categories/posts/reports/config → placeholder div）

## API 约定

所有管理接口前缀 `/api/admin`，需 ADMIN 角色。

| 模块 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 统计 | /api/admin/stats | GET | 系统概览统计数据 |
| 用户 | /api/admin/users | GET | 用户分页列表 |
| 用户 | /api/admin/users/:id | GET | 用户详情 |
| 用户 | /api/admin/users/:id/status | PUT | 启用/禁用用户 |
| 用户 | /api/admin/users/:id/roles | PUT | 修改用户角色 |
| 板块 | /api/admin/categories/tree | GET | 板块树 |
| 板块 | /api/admin/categories | POST | 新增板块 |
| 板块 | /api/admin/categories/:id | PUT | 编辑板块 |
| 板块 | /api/admin/categories/:id | DELETE | 删除板块 |
| 帖子 | /api/admin/posts | GET | 帖子分页列表 |
| 帖子 | /api/admin/posts/:id/top | PUT | 置顶/取消置顶 |
| 帖子 | /api/admin/posts/:id/essence | PUT | 加精/取消加精 |
| 帖子 | /api/admin/posts/:id/block | PUT | 屏蔽帖子 |
| 帖子 | /api/admin/posts/:id/move | PUT | 移动板块 |
| 帖子 | /api/admin/posts/:id | DELETE | 删除帖子 |
| 举报 | /api/admin/reports | GET | 举报分页列表 |
| 举报 | /api/admin/reports/:id | GET | 举报详情 |
| 举报 | /api/admin/reports/:id/handle | PUT | 处理举报 |
| 配置 | /api/admin/config | GET | 获取系统配置 |
| 配置 | /api/admin/config | PUT | 更新系统配置 |
| 敏感词 | /api/admin/sensitive-words | GET | 敏感词列表 |
| 敏感词 | /api/admin/sensitive-words | POST | 新增敏感词 |
| 敏感词 | /api/admin/sensitive-words/:id | DELETE | 删除敏感词 |
